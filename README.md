# KIP使い方Q&A

小中学校の教員・支援員が、KIP（子ども向けの感情理解・自己表現を支援するカードツール）の使い方に関する疑問を、自分で調べて解決できるWebアプリです。

## 公開URL

https://masasuzuki810-hash.github.io/kip-faq/

## どんな人の、どんな課題を解決するか

- **対象ユーザー**: KIPを授業や個別支援で使う教員・支援員（ITに詳しくない人も含む）
- **解決する課題**:
  - 「生徒にKIPを何と言って紹介すればいい？」「感情が高ぶっている子に使っていいの？」など、KIP運用中に出てくる疑問を、誰かに聞かなくても自分で調べられる
  - マニュアルを最初から読み返す手間をなくし、必要な質問だけをその場ですぐ探せる
  - スマートフォンからでも、教室や現場でそのまま確認できる

AIによる自動応答ではなく、あらかじめ用意されたQ&Aを検索・閲覧する形式のため、内容は常に一定で安心して参照できます。

## 使い方

1. 上記の公開URLをスマートフォンやPCのブラウザで開く
2. 上部の検索ボックスに知りたいキーワード（例：「モンスター」「保護者」「相談」など）を入力すると、質問・回答の両方から該当するものだけが絞り込まれる
3. 質問をタップ（クリック）すると回答が開閉する（アコーディオン形式）
4. 質問は「導入・基本」「カード選択後の指導」「困った時の対応・ワーク活用」「安全に関わる判断」「保護者向け」の5カテゴリに分かれて表示される
5. 検索ボックス右の「×」で検索文字をクリアできる

## 技術構成

- HTML / CSS / JavaScriptのみで構成された静的Webアプリ（ビルドツール不要）
- Q&Aデータは `data/qa.json` に分離されており、質問の追加・編集はこのファイルを編集するだけで反映される
- GitHub Pagesで配信

```
kip-faq/
├── index.html      # ページ本体（検索ボックス＋カテゴリ別Q&A一覧）
├── css/style.css   # デザイン（レスポンシブ対応）
├── js/main.js      # 検索・アコーディオン開閉のロジック
└── data/qa.json    # Q&Aデータ（質問はここに追加する）
```

## Q&Aを追加・編集する

`data/qa.json` に以下の形式でオブジェクトを追加するだけで、質問一覧に反映されます。

```json
{
  "id": "q16",
  "category": "導入・基本",
  "question": "質問文をここに書く",
  "answer": "回答文をここに書く。改行したい場合は \n で区切る。"
}
```

`category` は既存の5カテゴリのいずれかを指定してください（新しいカテゴリ名を指定した場合は、既存カテゴリの後ろに新しい区切りとして自動的に表示されます）。

## ローカルで確認する

ブラウザの `fetch` を使ってQ&Aデータを読み込むため、`index.html` を直接ダブルクリックでは正しく動作しません。簡易サーバーを立てて確認してください。

```bash
# Node.jsがある場合
npx serve .

# Pythonがある場合
python -m http.server 8000
```
